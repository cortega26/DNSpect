# Proveedores DNS incluidos

Dataset fuente: `data/dns_providers.es.json`

- **Cloudflare**: rápido y global, enfoque en rendimiento.
- **Google Public DNS**: infraestructura masiva y disponibilidad alta.
- **Quad9 (seguro)**: bloqueo de malware y dominios maliciosos.
- **Quad9 (sin filtrado)**: resolución sin restricciones; útil para pruebas.
- **OpenDNS (estándar)**: protección contra malware con filtros configurables.
- **OpenDNS FamilyShield**: bloqueo automático de contenido para adultos.
- **AdGuard DNS (estándar)**: bloqueo de publicidad, rastreadores y malware.
- **AdGuard DNS (familiar)**: bloqueo adicional de contenido para adultos.
- **CleanBrowsing**: perfiles de filtrado familiar y seguridad.
- **ControlD (sin filtrado)**: endpoint base sin bloqueos; latencia pura.
- **ControlD (antimalware)**: bloqueo de malware y dominios maliciosos.
- **ControlD (estándar)**: bloqueo de malware, anuncios y rastreadores.
- **ControlD (familiar)**: bloqueo adicional de contenido para adultos.
- **NextDNS**: personalización y privacidad.
- **DNS.Watch**: alternativa neutral sin filtrado agresivo.
- **Mullvad DNS**: orientado a privacidad.
- **UncensoredDNS**: enfoque en neutralidad y privacidad.
- **CZ.NIC**: operado por el registro .cz, bloquea malware.
- **Digitalcourage**: privacidad alemana, sin registro de consultas.
- **dns0.eu**: DNS europeo GDPR, bloqueo de malware.
- **LACNIC**: referencia regional LATAM.
- **NIC.br**: opción regional para comparación sudamericana.
- **AliDNS (Alibaba)**: referencia para rutas Asia/China.
- **DNSPod (Tencent)**: alternativa para desempeño en China.
- **Lumen / Level3**: resolvers históricos `4.2.2.x`.
- **Neustar**: DNS empresarial con protección contra amenazas.
- **Comodo Secure DNS**: énfasis en seguridad.
- **KT DNS (Korea Telecom)**: referencia para rutas hacia Corea del Sur.
- **Bharat DNS (NIC India)**: referencia para rutas hacia India.
